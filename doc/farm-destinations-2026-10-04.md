# ฟาร์ม Qmon — สุ่มคู่หูและทางเข้าอาคาร

อัปเดต 4 ตุลาคม 2026 ต่อจากแบบเกาะลอย

## ประสบการณ์ล่าสุด
หน้า /collection แสดงเกาะและอาคาร ไม่แสดงรายชื่อทั้งหมดต่อท้าย จึงไม่ยาวตามจำนวน Qmon ที่สะสม

- สุ่ม Qmon ร่าง 4 ที่เก็บเข้าฟาร์มแล้วครั้งละไม่เกิน 3 ตัวเมื่อเข้าหน้า ไม่ซ้ำกัน ไม่ต้องเลือกเอง ไม่อ่าน/เขียนการเลือกเก่าใน localStorage ไม่มีการสลับตัวกลางทางอัตโนมัติ
- แตะตัวที่เดินเพื่อดูชื่อและไปหน้ารายละเอียด ปุ่มพักยังใช้ได้
- อาคารฟาร์ม Qmon → /collection/qmon แสดงทุกตัวที่เก็บเข้าฟาร์มแล้ว รวมตัวซ้ำสายพันธุ์ มีชื่อ สายพันธุ์ และลิงก์รายละเอียดแต่ละตัว
- คลังไข่ → /eggs ใช้หน้าคลังไข่เดิม เพิ่มจำนวนไข่ที่ยังไม่ฟักและทางกลับฟาร์ม ระบบฟักเดิมคงอยู่
- มีป้ายชื่อและคำว่าแตะเพื่อดูบนอาคาร พร้อมปุ่มทางเข้าขนาดใหญ่ใต้แผนที่
- กล้องเริ่มที่ดูทั้งฟาร์ม และปรับมุมมองเมื่อขนาดหน้าจอเปลี่ยน

## การแยกอาคารด้วยภาพ
ฟาร์มเป็นโรงเรือนไม้เปิดกว้าง หลังคาแดงอิฐ มีตราอุ้งเท้า คอกและฟาง ใช้ทรงแนวนอน

คลังไข่เป็นอาคารรูปไข่สีงาช้าง หลังคาโค้งม่วง อยู่บนฐานรังและมีไข่ข้างประตู ใช้ทรงรีแนวตั้ง

โรงเรียนยังใช้กระท่อมหลังคา teal ตราเล่มหนังสือ จึงต่างจากสถานที่ใหม่ทั้งสอง

ภาพใช้จริง: public/farm/qmon-residence-v2.webp และ qmon-egg-storage-v2.webp โปร่งใส 640×640 สร้างด้วย built-in image_gen ต้นฉบับและ prompt อยู่ใน output/farm-phase1/

## ผังและข้อมูล
พื้นที่เริ่มต้นมีลาน + อาคารฟาร์ม + คลังไข่ อาคารทั้งสองเป็นทางเข้ารายการที่มีอยู่ ไม่ใช่โครงการที่ต้องซื้อ ผังขยายโรงเรียนยังรองรับอยู่ แต่ระบบก่อสร้างโรงเรียนยังไม่ได้เชื่อม

Qmon หลบฐานอาคารทุกประเภท เดินตามขอบและทางเชื่อม ข้อมูลรายชื่อทั้งหน้าเกาะและหน้าอาคารใช้ loader เดียวกัน ย้าย query เดิมโดยคงเงื่อนไขเจ้าของ Stage 4 และ is_active=false ไม่มีการเปลี่ยน schema หรือเขียนฐานข้อมูล

## การตรวจและข้อจำกัด
ทดสอบสุ่มไม่ซ้ำ/ไม่เกิน 3 ตัว/ไม่แก้รายชื่อเดิม และทางเดินหลบอาคาร รวมกับ tests ผังเดิม 5 กรณี ตรวจ TypeScript เฉพาะ src และ ESLint ไฟล์ที่แก้

ตรวจ browser ผ่าน isolated Next preview ที่ใช้ component จริงและข้อมูลทดสอบ หน้าอาคารใช้ FarmRoster ตัวจริง ส่วนหน้ารายละเอียดและคลังไข่ใน preview เป็น fixture เพื่อทดสอบทางเข้า ไม่ได้ทดสอบระบบฟักหรือข้อมูลบัญชีจริง ยังไม่ได้เผยแพร่

เอกสารแบบเก่าและภาพ isometric-expanded เป็นประวัติแบบก่อนหน้า ใช้ภาพ farm-destinations-v2-mobile.jpg สำหรับ UI ล่าสุด
