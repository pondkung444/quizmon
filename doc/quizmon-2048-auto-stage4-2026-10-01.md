# QuizMon 2048: Stage 4 Auto skills

Implements the 36 locked skills and the ten implementation decisions approved on 1 October 2026. Source: https://app.notion.com/p/3ec7cdca67f181dbabe0dc6a955850b7

- New runs opt into `skillVersion: 1`. Saved runs without this flag keep their existing engine; start a new journey to use the new system. The account save key and schema version 3 remain unchanged.
- Stage 1–3 have no Auto. Stage 4 resolves egg × canonical art lane × personality A/B from the companion snapshot. Uses the existing SPD cooldown formula and pet-only power. Charge persists across rooms; statuses and marks clear at victory.
- Valid swipe order: move/merge geometry → existing skill periodic effects → mark result conversion/number override → normal rune effects → supplementary skill effects → garden neighbor doubling → status aging → finish check → spawn → Auto and mirror → enemy attack/reduction → surviving counters/new armor → roots → board recovery. Rune/relic bonus charge is applied before Auto.
- Supplementary effects use raw power without combo, criticals, or Echo; the ordinary rune output retains its bonuses. Active rune buffs apply before output rounding, and only modify newly created periodic/counter stacks. Recast refreshes statuses/quotas rather than stacking multipliers.
- Marks sample all 16 sockets uniformly, including empty sockets, using the saved run RNG. A mark stays on its socket and triggers only a merge destination. An existing mark is retained. Garden resolves ordinary output for all pairs before doubling adjacent tiles, preserves adjacent awake/root state, and does not emit extra effects. Number mark uses the new output number and its awakening threshold. Divine blessing emits three total rounds.
- Skill number doubling saturates at 2^30 as a technical bound; it does not emit effects, count a merge, or release roots. Tied low-number targets use row-major order. Missing targets do not defer Auto or refund charge. Integer immediate effects use floor; enemy stance reduction follows existing rounding.
- UI: Auto charge/detail below Qmon, tappable status icons for both combatants, socket mark/detail, short name/element cue and sound on every cast, tile flashes, mark placement/activation flashes. CSS effects respect reduced motion and add no animation wait to input. Existing artwork/SFX are reused, with stronger glow for Epic/Legendary.

Validation: five forest2048 test programs pass, including all 36 casts, save state, no-op/status lifetimes, marks, simultaneous garden merges, awakening, roots, absent targets, surviving/lethal counters, charge carry, and relic interactions. Headless Edge with account/API fixtures casts all 36 skills, checks 320×480, 320×568, 390×844, 430×932, status detail/reload, and Stage 2 fallback. This is engine/UI verification, not owner playtest, physical-device pilot, or balance evidence.

The API, ownership checks, learning counters, EXP, pet stats, and economy rewards are unchanged. Owner playtest and balance tuning remain next.
