# Raid รอบสั้น — กติกา 3

ผู้เล่นต้องการตอบคำถาม 5–8 ข้อแล้วจบรอบ เล่นเพื่อสนุกและลุ้น ลดการอ่านท่าบอสและการจัดการทรัพยากร

- เชิงหมอกจางไม่เกิน 5 ข้อ สันลมโหม 6 ข้อ ยอดฟ้าคำราม 8 ข้อ บอสล้มก่อนจบได้ทันที
- สองการ์ดใช้ฟรีทุกข้อ: ตีแรง / ตีพร้อมฟื้นเลือด ทุกการ์ดทำดาเมจ ไม่มีเกจพลัง การแพ้ทาง หรือการรอจั่ว
- ตอบถูกโจมตีเต็มแรงแน่นอน แล้วลุ้นคริติคอล 1.5 เท่า โอกาส 15–45% ตาม FOC/SPD
- ตอบผิดทำดาเมจพื้นฐาน 25% ไม่มีคริติคอล การ์ดฟื้นเลือดยังฮีลครึ่งหนึ่ง
- ATK เพิ่มดาเมจแบบมีเพดาน HP/DEF ช่วยยืนระยะ ไม่มีเงื่อนไข stat ขั้นต่ำหรือเปอร์เซ็นต์ตอบถูกซ้ำอีกหลังบอสล้ม
- ดาเมจบอสเบาลง ไม่เร่งพลัง ไม่ต้องจำท่า ครบข้อแม้บอสยังอยู่ก็จบรอบและรับของตามผลงาน
- คงสูตรรางวัลเดิม: ชนะคะแนน 80–100 ตามเลือดคงเหลือ; ไม่ชนะตาม % เลือดบอสที่ลดได้ สูงสุด 79 ไม่เปลี่ยนไข่ครั้งแรก/pity หรืออุปกรณ์ร่วมกับ PvP
- คงการสุ่มคละวิชา/บทแยก junior/senior, ไม่ซ้ำข้อในรอบ, รูปโจทย์ และ Sarabun

## ความเข้ากันได้

`engineV2.ts` เก็บกติกา 2 แบบเดิม รอบที่มี snapshot version 2 เล่นต่อด้วยกติกาเดิม ทั้ง UI/เซิร์ฟเวอร์/SQL ส่วนรอบเริ่มใหม่ใช้ version 3 ไม่เปลี่ยน version กลางรอบหรือสุ่มโจทย์ที่เปิดค้างใหม่

Apply migration `raid_short_rounds_v3` ก่อนปล่อยแอปใหม่ รองรับ state 2/3 แต่ห้ามสลับ version ของรอบที่เริ่มแล้ว RPC ตรวจจำนวนข้อและสองการ์ดฟรี การตอบและรับของซ้ำยังเป็น idempotent และยังเรียกตัวบันทึกผลได้เฉพาะ service_role

## การตรวจ

ชุด `npm run test:raid` ครอบคลุมกติกา 2 เดิม, การสุ่มคละช่วงชั้น, กติกา 3 และ SQL จริงบน PGlite รวม 21 tests ทดสอบทุกด่านทั้งถูกทั้งหมด/ผิดทั้งหมด สเตตัส 0–500, ไม่เกิน 5/6/8 ข้อ, ไม่มีพลังการ์ด, ฮีลไม่เกินเลือดสูงสุด, ไม่มีเงื่อนไขชนะซ้อน, ห้ามเปลี่ยน version, รีทรายตอบและรับของไม่ซ้ำ

สคริปต์ `simulate.ts` และผลจำลองเก่าเป็นกติกา 2 เพื่อเก็บหลักฐานเดิม ไม่ใช่ตัวเลขสมดุลของกติกา 3
