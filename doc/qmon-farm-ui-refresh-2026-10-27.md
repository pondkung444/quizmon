# Qmon Farm UI refresh — 27 ตุลาคม 2026

## ขอบเขต

ผู้ใช้เลือกแนวทาง 2 “คู่หูชวนทำภารกิจ” แล้วสั่งให้สำรวจและปรับ UI ภายในฟาร์มทั้งหมด ใช้ oil-ui 0.25.0 และตรวจ React components ตาม react-best-practices เริ่มจาก origin/main 600ea2e ใน branch codex/qmon-farm-ui-unification ของ worktree แยก ไม่แก้งานค้างใน checkout หลัก

สำรวจจาก source ของหน้า /collection และหน้าลูก: โรงเรียน/สวนเดิม แบบสร้าง/บทเรียน พัซเซิล คิวโครงการ/ทีม ผัง/วางสวน ประวัติ/ทบทวน Qmon/สมุดสะสม และเยี่ยมเพื่อน/กำลังใจ จากนั้นตรวจหน้าทดลองที่ใช้ components จริงด้วยข้อมูลจำลอง ปัญหาหลักคือ controls ทับแผนที่ สี/ตัวอักษรหลายชุด ทางนำงานถัดไปไม่ชัด และการเริ่มงานใช้เหรียญทันที

## สิ่งที่เปลี่ยน

- FarmShell รวมเมนูภายใน 4 หมวด ฟอนต์ Anuphan และสีลาเวนเดอร์/ม่วงตามแบบที่เลือก จำกัด theme override ขณะอยู่ในฟาร์ม รักษา theme preference เดิมเมื่อออกจากฟาร์ม
- หน้าเข้าฟาร์มแสดงก้าวถัดไปตามโรงเรียน/สวนจริง: ฟักไข่เมื่อยังไม่มีคู่หู เริ่มโรงเรียนฟรี รอ/พัก/ช่วยงาน วางโรงเรียน เรียนแบบสวน และเข้าคิวก่อสร้าง การครบเวลาคำนวณเพื่อแสดงผล ไม่เขียนเปลี่ยนสถานะงาน
- แผนที่และกล้องใช้พื้นที่พอเหมาะ ปุ่ม/ข้อความอยู่ใน flow ของหน้า ไม่ซ้อนกัน ยังเลื่อน/ซูม ดูทั้งหมด จัดผัง สมุดสะสม และเลือก Qmon ได้
- โรงเรียน สวน แบบสร้าง บทเรียน และกรอบพัซเซิลใช้สี/ขนาดปุ่ม/ตัวอักษรเดียวกัน เก็บ texture/ภาพเกมและกลไกวาง/หมุนเดิม แถบขั้นตอนโรงเรียนเป็นลำดับเดียว
- งานใหม่และสวนเดิมเพิ่ม dialog ทบทวนหัวหน้า ราคา และยอดคงเหลือก่อนเรียกคำสั่งเดิม ยกเลิกไม่ส่งคำสั่ง ปิด/เปลี่ยนทีมไม่ได้ระหว่างบันทึก retry ใช้ request ID เดิมจนสำเร็จ ยอดหลังสำเร็จมาจาก server ไม่หักเองฝั่ง UI
- คิวงานลดสิ่งที่ยังเกินระดับโรงเรียน ผู้เล่นระดับ 0 มีทางไปโรงเรียนฟรีแทนรายการที่เริ่มไม่ได้ทั้งหมด รายการเต็มยังดูในแบบสร้างได้
- ประวัติ/เยี่ยมเพื่อน/ผังและเมนูเกมเดิมใช้ shared tokens ไม่เปลี่ยนสิทธิ์ การส่งสติกเกอร์ หรือกติกาสะพาน

ไม่แก้ราคา เวลารอ deadline snapshot รางวัล migration สิทธิ์ฐาน หรือ action/RPC ของเกม ไม่ปรับเหรียญ/เวลา/ผัง/ความคืบหน้าบัญชีจริง ไม่แตะหน้าแรก /pet ตามข้อตกลงเดิม

## ผู้ตรวจอิสระ oil-ui

Visual review /root/visual_review ให้ 7/10 ในรอบก่อนแก้ พบสี UI บ่อยังแยกชุด ขั้นตอนโรงเรียนตัดบรรทัด และความแน่นของ header/form แก้สีรอบบทเรียน/ปุ่ม ขั้นตอน 5 ช่อง ลำดับสถานะ/เวลา และความสมดุลภาพคู่หูแล้ว ไม่อ้างคะแนนใหม่หลังแก้

UX walkthrough /root/ux_review ทดลองจริงเฉพาะ dev preview ทั้งแนวตั้ง/แนวนอน: เลือกหัวหน้า → ยืนยัน → คำตอบขาดหาย → retry สำเร็จ เหลือ450เหรียญและ1/2ช่องงาน พบ error/retry ต่ำกว่าจอแนวนอน จึงปรับ dialog ให้กระชับและวาง feedback/actions ชิดขอบล่าง แล้ว main agent ตรวจ visibility ซ้ำ 3 รอบ ผู้ตรวจไม่ได้เดินเส้นทางวางผ่านบัญชีจริง

หลักฐานภาพ/report อยู่ใน .oil-ui/farm-ui-unification ของ worktree (ไม่ commit ข้อมูลชั่วคราว) และรายงาน UX แยกใน .oil-ui ของ checkout หลักตามพื้นที่ที่ผู้ตรวจเขียน เครื่องมือ evidence เก็บภาพ1x/2xสำเร็จ แต่ไม่มี ffmpeg สำหรับวิดีโอเต็ม จึงไม่อ้างว่าทบทวน motion จากวิดีโอครบ; คำเตือนไม่มี scroll animation ในเกมเต็มจอคงไว้ เพราะเป็นหน้าควบคุมเกม ไม่ใช่หน้าเล่าเรื่อง
